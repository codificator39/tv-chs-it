# Avviso
I loghi presenti in questo repository sono di proprietà dei rispettivi titolari (emittenti televisive) e vengono utilizzati esclusivamente a scopo identificativo/informativo (fair use).

Questo repository non è affiliato, sponsorizzato o approvato da nessuna delle aziende o emittenti i cui marchi/loghi compaiono qui. Tutti i marchi, nomi e loghi restano di proprietà dei rispettivi detentori.

Se sei il titolare di uno dei loghi qui presenti e desideri che venga rimosso, apri una Issue o contattami: provvederò alla rimozione il più tempestivamente possibile.
